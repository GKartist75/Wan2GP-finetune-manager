✨ Finetune Manager

A plugin for Wan2GP that lets you discover, create, and share finetunes with the community

Finetunes are like presets or recipes — they contain model URLs, settings, and descriptions that make Wan2GP generate a certain style of video. This plugin is your hub for finding new finetunes, making your own, and sharing them with others.

🛡️ Security and trust — check URLs yourself

⚠️

The registry is community-contributed. The plugin checks the recipe structure and URL policy — HTTPS only, no credentials, no local/private hosts, no bare filenames or embedded HTML — but that is a guardrail, not a safety guarantee. It cannot prove the uploader is honest or that the file behind a URL is safe. Always check the URL yourself before downloading.

🔎 Before you download

  • Open the details and confirm every URL starts with https:// and uses a host you expect, normally huggingface.co, civitai.com or civitai.red. Browse and Local badge other download hosts with check host: … — it is a warning, not a block.
  • Publishing is stricter: Save & Upload and Upload to Registry reject recipes whose download URLs use another host. Save them locally if you still want to use them yourself.
  • Check the repository, path and filename. Lookalike accounts and re-uploads can reuse the same name and description.
  • Prefer entries that publish a SHA-256, and verify it where the host provides one. A matching hash proves the bytes match; it does not prove they are safe.
  • Treat .ckpt, .pt, .pth, .bin, .gguf and .safetensors files from strangers with caution. Do not load one just because it is listed here.
  • Never put a Hugging Face or CivitAI token in a finetune JSON or a shared recipe. Tokens belong only in your local, gitignored config.json.
  • Report malicious or broken entries through GitHub Issues.

🔍 Browse — Discover finetunes from the community

📡 Refresh the registry browse

Click Refresh Registry to fetch the latest finetunes from the community hub on Hugging Face. You'll see cards with names, descriptions, and tags — just like browsing an app store.

🔎 Search & filter browse

Type in the search box to find finetunes by name or description. Use the Model family dropdown to show only LTX-2, MiniMax H3, Wan2.2, Flux 2, Qwen Image, Krea 2 and the rest of Wan2GP's families. The Architecture dropdown narrows to the selected family, and Tag narrows by topic.

🗂️ Grouped by model family browse

Cards are grouped under family headings with a count, and each card shows its family and architecture badges. A looks like … warning appears when the model's name clearly points at a different family than its architecture — the JSON is not changed automatically.

📄 Preview details browse

Click any card to see its full JSON — all the URLs, LoRAs, settings, and metadata. You can inspect everything before downloading.

✅ Validate URLs browse

Not sure if a finetune's model files are still online? Click Validate URLs to check every URL in the finetune — it'll tell you which ones work and which are broken.

📥 Download browse

Found something you like? Click Download and it's saved to your local finetunes folder, ready to use in Wan2GP.

  • Select a finetune card
  • Click Download
  • It appears in your Local tab and in Wan2GP's model list

✏️ Create / Edit — Build or tweak finetunes

🆕 Create a new finetune create

Fill in the form with a name, description, model URLs, LoRAs, and all the settings you want. When you're happy, click Create to save it locally or Save & Upload to share it with the community.

  • Enter a name (like "My Cinematic Style")
  • Pick an architecture — choices are labelled with their family (for example LTX-2 · ltx2_22B)
  • Add model URLs and LoRAs
  • Tweak settings (steps, guidance, resolution)
  • Save locally or upload to the registry

📝 Edit an existing finetune edit

Load any finetune from Browse, Local, or the Import button, and all its fields fill into the form automatically. Change what you want, then save the updated version.

🚀 Improve from registry edit

Found a finetune that's almost right? The Improve button loads it into the editor so you can tweak it and save your own improved version.

💾 Save & Upload edit

Save Locally keeps it on your machine. Save & Upload also publishes it to the community registry so everyone can use it. Uploaded finetunes appear immediately in Browse for others.

📤 Export as file edit

Click Export to download your finetune as a .json file — share it with friends, back it up, or import it later.

💡

Pro tip: The editor has sub-tabs — URLs, LoRAs, Resolutions, Settings, Prompt Enhancer, and Help. Everything is organized so you don't get lost in a giant form.

📂 Local — Manage files on your computer

📋 See all your local finetunes local

Click Refresh to see every finetune JSON file in your Wan2GP finetunes folder. Each one shows as a card with its name, family, architecture, and description, grouped under family headings.

🔎 Filter locally local

Use Search, Model family, and Architecture above the Local cards. The Architecture dropdown only lists types that belong to the selected family.

📄 Preview any finetune local

Select a card to see its full contents in the JSON viewer — everything inside the file at a glance.

📂 Load into the editor local

Click Load & Switch and the finetune opens in the editor tab, ready to modify. All fields auto-fill.

🗑️ Delete a local finetune local

Select one and click Delete — it asks for confirmation first so you don't accidentally remove something.

☁️ Upload to registry local

Have a finetune on your machine that you want to share? Select it and click Upload to Registry — it publishes to the community hub instantly.

📥 Import from a .json file local

Got a finetune file from a friend or downloaded elsewhere? Click Import, pick the file, and it's added to your local collection. You'll see a preview of its contents before importing.

  • Click the file picker and select a .json file
  • Preview its contents in the viewer
  • Click Import to add it to your local finetunes

🎨 CivitAI — Pull models from CivitAI

🌐 Search CivitAI civitai

Search the CivitAI model library directly from the plugin. Type a query (like "fantasy landscape" or "anime style") and see matching results.

✨ Auto-fill into editor civitai

Found a model you like? Pick a version in Result version, click Fill Selected into Create/Edit, and its download URL is placed in the right field — LoRAs for LoRA/LoCon/DoRA models, main checkpoints for everything else. Tweak the rest in the Create / Edit form and save from there.

💡

Pro tip: Use CivitAI to find models, then use Improve from the Browse tab to pull registry finetunes into the editor. Between the two, you rarely need to type URLs manually.

🧩 Pack — The curated adult catalog

🔞 Turn it on first pack

The Pack tab is off by default. Tick Enable the adult pack and confirm you are 18 or older; nothing downloads until you press a download button. The catalog appears only after both boxes are ticked.

📋 Catalog — act on one item pack

One row per item with its live state: missing, installed, stale, partial or no recipe. Filter by text or model family, choose custom to see only what you added yourself, then pick a row and use Download this, Write recipe, Load gallery or Delete this. A checkpoint's weights and its recipe are separate actions, so you can read the recipe before fetching tens of GB.

🔎 Find & Add — inspect before you add pack

Search or browse HuggingFace and CivitAI from inside the plugin, then press Inspect to see the files inside a result: kind, size, whether it is a HIGH or LOW half, and the first 16 characters of its SHA-256. On CivitAI, CivitAI version switches release and re-inspects.

  • Pick the Wan2GP architecture so the item lands where Wan2GP looks for it
  • Choose Add as: auto / lora / checkpoint — auto trusts the file's own classification
  • Press Add selected file: it joins your catalog and downloads from the Catalog tab
  • Add by link resolves a HuggingFace repo, a CivitAI model URL, or a bare CivitAI model id

🔄 Updates — pin, then download pack

Check compares local files with the catalog. Check online also reads each source's live size and hash, which needs network. Nothing changes until you choose: Apply selected pins the accepted hash and size (and the CivitAI version), then Download selected fetches exactly those bytes.

⚠️

Pinned means pinned: downloads use the hash you accepted, and a CivitAI release stays on the version you reviewed instead of following "latest". Re-apply an update whenever you want to move forward.

⚡ Quick Start — common workflows

  1. I want to find and use a finetune — Go to Browse → Refresh Registry → Select a card → Download
  2. I want to tweak an existing finetune — Browse or Local → select → Load & Switch → edit fields → Save Locally
  3. I want to share my own finetune — Create / Edit → fill form → Save & Upload
  4. I found a model on CivitAI — CivitAI tab → search → Fill into Editor → tweak → Save & Upload
  5. I got a .json file from someone — Local tab → Import → pick file → Load & Switch
  6. I want the curated adult pack — Pack → enable + confirm 18+ → Catalog → pick → Download this
  7. I want a model that is not in the catalog — Pack → Find & Add → Inspect → pick file → Add selected file
